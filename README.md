# シブガレット（cigarette-app）

カメラに映したペンを認識し、ペンの位置・角度・長さに合わせて**タバコの CG を重ねて表示する**、ブラウザで動く AR アプリです。
口元に近づけると火の先から煙が上がり、口をすぼめると口から煙を吐く演出になります。親指と人差し指の着火ジェスチャーやライター（に見立てた小物）で「着火」でき、人差し指でトントンと叩くと灰が落ち、60 秒燃えるとシケモクになります。
渋い色調のフィルターをかけて、AR の写真を撮影・保存できます（iOS アプリは写真アプリ、Web 版はダウンロード）。

> **注意**：機能はすべて合成画像・写真・仮想カメラを使った自動テストで確認したものです。**実際のカメラ・実際のペン・スマートフォンでの動作は、まだ確認していません**（「現在の実装状況」参照）。

## 画面

下部のタブで 3 つの画面を切り替えます（見た目は「ここで一句」の和紙・墨・朱の作りを参考にしました）。

| 画面 | 内容 |
| --- | --- |
| 撮る（中央） | カメラの映像・フィルター・カメラの切り替え・撮影だけ。数値の調整は出しません |
| 設定 | 判定の数値・色・CG・煙・着火などの調整（上に小さく映像を出したまま調整できる）、開発者向けの表示 |
| 遊び方 | ジェスチャーと操作の説明 |

## 主な機能

| 機能 | 内容 |
| --- | --- |
| ペンの認識 | OpenCV.js で、色（ピンク・青・緑・赤、画面をタップして登録した色）と形（細長さ・直線性・幅の均一性など）からペンを認識。指でペンが分断されても 1 本として扱う |
| タバコ CG | ペンの位置・角度・長さ・太さに合わせてタバコの CG を重ねる。CG の種類は タバコ / 葉巻 / パイプ / 自動 から選べる |
| 口元の検出 | MediaPipe Face Landmarker で唇の位置と口の形を取得し、口元に近い端を吸い口にする（向きの自動補正） |
| 煙 | 吸う（タバコの先から煙）・吐く（口から煙）を状態機械で判定し、パーティクルで描く。量・速度・広がり・濃さを調整できる |
| 着火 | MediaPipe Hand Landmarker による着火ジェスチャー（親指と人差し指）、または単色の長方形の小物をライターとして認識し、炎を出す。描いた炎のどこかをタバコの先に当てると着火し、着火中だけ煙が出る |
| 着火ジェスチャー | 親指と人差し指の先をくっつけてから素早く離すと、人差し指の先に炎が出る（STEP 10 で中指の指パッチンから変更）。手の大きさで正規化した距離で判定し、手のひら側・手の甲側・斜めのどれでも、左右の手のどちらでも判定する想定。ペンをつまんでいる指では判定しない。接触距離・接触の解除距離・離れる距離・速さ・接触時間・制限時間・クールダウンを調整できる。STEP 11 で、軽くくっつけて素早く離すだけで成功しやすいようにしきい値と判定を見直した。STEP 12 で、タバコを持っている手（指とペンの位置から推定）では判定しないようにした（灰落としは使える） |
| SNAP! | 着火ジェスチャーに成功した瞬間、人差し指の先の上に「SNAP!」とコミック風の文字が出る（約 0.6 秒、衝撃線・火花付き。写真にも写る） |
| 指先の炎 | 炎は 5 秒間（STEP 9 までは 2.5 秒）、人差し指の先端に追従する。別の手へは飛び移らず、手を見失ったら少し保持してから消える。炎を出している手を振ると消える（タバコの火は消えない。設定で OFF にできる） |
| 灰落とし | 着火中は先端に灰がたまる。人差し指でタバコを 2 回トントンと叩くと、灰が崩れて落ちる（近さと動きから推定。別の人の指では落ちない） |
| シケモク | 着火して映っている時間が合計 60 秒になると、巻紙が焦げ茶〜黒に焦げたシケモクになり、火が消えて再着火できない。CG の長さは変わらない（下のペンが見えない）。画面の外に出して戻すと新品になる |
| 正面の吐煙 | 顔が正面を向いているときは、口元の中央からカメラの方へ左右対称に膨らむ煙、横を向くと横に噴き出す煙（その間は滑らかに補間） |
| 遠距離認識モード | 小さく写った遠くのペンを、顔・手・小さい色の候補の近くだけカメラの映像から高解像度で切り出して、厳しい判定で認識する（初期値 OFF、「設定 → 検出結果」で ON） |
| フィルター | Normal / Sepia / Noir / Vintage を画面上部のボタンで切り替える。フィルターはカメラの映像だけにかかり、タバコ CG・炎・煙にはかからない。ペンの認識はフィルター前の映像で行う |
| カメラの切り替え | 画面右上のボタンで、インカメラ・アウトカメラを切り替える（左右反転も自動で切り替え）。切り替えに失敗したら元のカメラに戻る |
| 写真 | 画面下部のシャッターで、映像・フィルター・AR を 1 枚に合成して撮影する。プレビューで「保存」か「撮り直す」を選ぶ |
| 映画ポスター | 撮影した写真を「ポスターにする」で映画ポスター風に加工する。作風は 海外映画風 / アニメ映画風 / ノワール風 / 脱力ネコ風（猫耳）/ カオス・クラウン風（白い顔・赤い口元）/ 紳士シェフ風（金髪の前髪・スーツ）。タイトル・キャッチコピーは Gemini で生成（未設定・失敗時は定型文）し、編集して保存・共有できる |
| 複数人 | 1 人 / 2 人 / 3 人モード。顔とペンに追跡 ID を付け、ペンを持ち主に割り当てて、人物ごとに着火・煙を管理する |

## 使用技術

- Vite 8 + React 19 + TypeScript 6
- OpenCV.js（`@techstark/opencv-js`）：ペン・ライターの認識
- MediaPipe Tasks Vision（`@mediapipe/tasks-vision`）：顔（Face Landmarker）と手（Hand Landmarker）の認識。モデルは `public/models/` に同梱
- Canvas 2D：タバコ CG・炎・煙の描画
- Gemini API（任意）：ポスターのタイトル・キャッチコピーの生成。API キーは Mac 側のサーバー（`server/posterServer.ts`）だけが持つ
- Capacitor 8：iOS アプリ化（中身は同じ Web 版を WKWebView で動かす）。写真の保存はアプリ内のプラグイン（`ios/App/App/PhotoSaverPlugin.swift`、PhotoKit）
- oxlint（Lint）、Node.js 標準の `node:test`（単体テスト）

画像の処理と推論は**すべて端末内**で行い、カメラの映像を外部に送信しません（ポスターの AI 生成でも、送るのは作風とお題の文字だけで、写真は送りません）。

- MediaPipe（1.1.1）が自動で行う利用統計の送信（`odml.pa.googleapis.com`）も止めています（`src/lib/telemetryGuard.ts`）。
- 利用統計には映像は含まれません。

## 必要な開発環境

- **Node.js 24**（`.nvmrc` に記載）と npm
  - nvm を使う場合：`nvm use`
  - Homebrew の場合：`brew install node@24` のあと、そのシェルで `export PATH=/opt/homebrew/opt/node@24/bin:$PATH`（グローバルの `brew link` は変えなくてよい）
- カメラの付いた PC と、Chrome などのブラウザ
  - ブラウザがカメラを使えるのは `localhost` か HTTPS のページだけです。

## インストール手順

```sh
git clone https://github.com/t-owada-chibatech/cigarette-app.git
cd cigarette-app
npm install
```

## ローカルでの起動

```sh
npm run dev
```

表示された `http://localhost:5173/` をブラウザで開き、「カメラ起動」を押してカメラの使用を許可します。

- 初回は OpenCV.js（約 13MB）と MediaPipe の読み込みに数秒かかります。
- **スマートフォンのブラウザ**：
  - 同じネットワークの PC から開くと `http://` になるため、カメラを使えません。
  - HTTPS で配信する設定は、まだ用意していません。iPhone では、下の iOS アプリを使います。

## 映画ポスターの AI 生成（任意）

タイトル・キャッチコピーを Gemini で生成するときだけ必要です。設定しなくても、作風ごとの定型文でポスターは作れます。

1. `.env.example` を `.env.local` にコピーし、`GEMINI_API_KEY=` に自分の API キーを書く（`.env.local` は Git に含めません。キーをアプリやブラウザのコードに書かないでください）。
2. Web 版：`npm run dev` を起動し直すと、同じサーバーの `/api/poster-copy` で生成できます。
3. iPhone のアプリ：Mac で `npm run poster-server` を起動し、表示された `http://<Mac の IP>:8787` を、ポスター画面の「AI の接続先」に入力します（iPhone と Mac は同じ Wi-Fi）。初回は「ローカルネットワーク」の許可を求められます。

## iOS アプリ（Capacitor）

必要なもの：macOS、Xcode（27.0 で確認）、iPhone（iOS 16.4 以上）、Apple アカウント（無料のアカウントでも自分の iPhone へのインストールは可能）。

```sh
npm install
npm run ios:sync    # Web 版をビルドして ios/App/App/public にコピー（npm run build && npx cap sync ios）
npm run ios:open    # Xcode でプロジェクトを開く（npx cap open ios）
```

Xcode での手順：

1. Xcode で **App** ターゲットの **Signing & Capabilities** を開き、**Team** に自分の Apple アカウント（Personal Team など）を選ぶ。
   - **Bundle Identifier**（既定は `io.github.towadachibatech.shibugarette`）が他と重複していると言われたら、自分用の値に変える。
2. iPhone を USB で接続し、iPhone 側で **設定 → プライバシーとセキュリティ → デベロッパモード** をオンにする（初回のみ。再起動が必要）。
3. Xcode の上部の実行先に自分の iPhone を選び、▶（Run）を押す。
4. 初回は iPhone 側で **設定 → 一般 → VPN とデバイス管理** から、自分の開発元を信頼する。
5. アプリを開き、「カメラ起動」を押して、カメラの使用を許可する。
6. 写真を保存するときは、初回に「写真の追加」の許可を求められる（許可しなかった場合は、**設定 → シブガレット → 写真** で変更できる）。

iPhone で求める権限（`ios/App/App/Info.plist`）：

| 権限 | 用途 |
| --- | --- |
| カメラ（`NSCameraUsageDescription`） | ペン・顔・手の認識と AR の表示。映像は外部に送信しない |
| 写真の追加のみ（`NSPhotoLibraryAddUsageDescription`） | 撮影した写真を写真アプリに保存する。写真の読み取りはしない |
| ローカルネットワーク（`NSLocalNetworkUsageDescription`、`NSAllowsLocalNetworking`） | ポスターの AI 生成で、同じネットワークの Mac のサーバーに接続する（写真は送らない） |

マイクは使いません。

- Web のコードを変えたら、`npm run ios:sync` をやり直してから Xcode で Run します。
- OpenCV.js・MediaPipe の WASM とモデルはアプリに同梱しているので、オフラインでも動く想定です（未確認）。

## 既知の制約

- **元のペンは消えません**。CG はペンの上に重ねて描くだけなので、CG からはみ出した部分のペンは見えます。
- ペンの先端と後端は区別しません。吸い口の向きは、口元に近い端で決めます。
- 色と形でペンを認識するので、同じ色で細長い物（ストライプの服・ケーブルなど）をペンと誤認識することがあります。
- 吐く動作は口の形（口すぼめ）で判定する擬似的なもので、実際の息は検出しません。
- 処理は 2D で、奥行きは考慮しません（指パッチンの判定だけは、手の 3D のランドマークを使います）。
- フィルターは映像全体（人物を含む）にかかります。背景だけにかける機能は、処理が重くなるため今後の課題です。
- 写真の AR は処理解像度で描いたものを拡大するので、映像より少しぼやけます。
- 着火ジェスチャーは厳密な指パッチンではありません。灰落としも、指がタバコに触れたかは確定していません（近さと動きによる推定）。
- 映画ポスターの顔のパーツ（猫耳・メイク・前髪・スーツ）は、撮影時の顔の位置に Canvas で描いた図形で、髪や服を本当に変えるわけではありません。顔が見つからないときはパーツなしになります。
- タバコを持っている手では着火ジェスチャーができません（もう一方の手を使います）。持っているかは指とペンの位置からの推定なので、握り方によっては判定を誤ることがあります。
- 着火しやすくするため着火距離を広げたので、炎の近くを通っただけでも着火することがあります。
- 画面外への退出は推定で、うまく判定できないときは開発者向けの表示の「新品に戻す」で戻せます。
- 遠距離認識モードは、顔が小さすぎて見つからないときは色の候補だけで探すので、背景の細長い同じ色の物を誤認識することがあります。
- フィルターのために映像と AR を 2 枚の canvas に分けたので、PC のテストでは fps が約 8% 下がりました（iPhone では未計測）。
- スマートフォン（iOS アプリを含む）での動作・性能は未確認です。iOS アプリは、バックグラウンドから戻ると「カメラ起動」を押し直す必要がある見込みです。
- その他の制約は、技術仕様書の第 20 章にまとめています。

## 共同開発の進め方

1. `main` から作業用のブランチを作る：`git switch -c feature/作業内容`（例：`feature/smoke-color`、`fix/lighter-detection`）
2. 変更したら `npm run build`・`npm run lint`・`npm test` がすべて通ることを確認してコミットする。
3. `git push -u origin feature/作業内容` で push し、GitHub で `main` への Pull Request を作る。
4. 他のメンバーがレビューしてから `main` にマージする。

その他の注意：

- `main` への直接の push や force push はしない。
- `.env` などの認証情報・個人情報・大きなデータは、コミットしない（`.gitignore` で除外している）。
